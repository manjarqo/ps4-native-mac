# PS4 Native engine (plan 1 of 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give `ps4-recomp` the engine subcommands the PS4 Native app needs: `inspect`, `import`, `analyze-game` and `build --json`. With them a fake-signed PKG or a dumped folder becomes a signed, launchable .app, driven entirely from the command line with machine-readable progress.

**Architecture:** New focused Go packages under `pkg/`:
- `sfo` reads param.sfo;
- `events` writes the JSON lines;
- `fpkg` parses PKG and PFS and extracts them;
- `library` owns the on-disk layout and import;
- `compat` is the support database.

`pkg/cli` dispatches the new subcommands and adds JSON progress and an SFO-driven Info.plist to the existing build. The PKG/PFS crypto and layout are ported from shadPS4's GPL-2.0 extractor, keeping its attribution.

**Tech Stack:** Go 1.27.1 (module `ps4-recomp`), standard library only (`crypto/aes`, `crypto/rsa`, `crypto/sha256`, `compress/zlib`, `encoding/binary`, `encoding/json`). macOS `codesign`/`xattr`, as today.

**Spec:** `docs/superpowers/specs/2026-10-26-game-manager-design.md`

## Global Constraints

- Inputs are fake-signed PKGs (CATEGORY `gd` game, `gp` patch, `ac` DLC) and dumped folders. **Retail PKGs are detected and rejected with:** "this PKG is encrypted with console keys; use a dump of your own console or an fpkg". The engine never tries to decrypt them.
- Every new subcommand takes `--json`. With it, stdout carries exactly one JSON object per line, each with `"event"` set to `"progress"`, `"warning"`, `"error"` or `"done"`. The exit code is 0 on success and non-zero after an `error` event. Without `--json` it prints human text.
- Library root (`--library`; the app passes `~/Library/Application Support/PS4Native`): `library.json` and `games/<TITLE_ID>/{content,build,logs}`. DLC goes to `content/addcont/<entitlement>`.
- Imports are atomic and resumable. Work goes to `content.partial/`, which is renamed to `content/` only on success. On resume, files whose size and SHA-256 match are skipped.
- The bundle id is `org.ps4native.<TITLE_ID>`, CFBundleDisplayName is TITLE and CFBundleShortVersionString is APP_VER, taken from param.sfo when the game has one. Today's `org.ps4recomp.<eboot>` values stay as the fallback for an ELF without an SFO.
- Support statuses: `playable`, `in_progress`, `other_version`, `experimental`, `unsupported_input`.
- No game data in the repository. PKG tests use synthetic packages generated by test code.
- AGENTS.md:
  - no stubs, no fake tests, no temporary solutions;
  - comments and docs in English;
  - Go analysis tools clean (`go vet`, `gofmt`), and keep allocations low;
  - ask the owner before downloading anything.
- Builds use `go build -buildvcs=false` in worktrees with symlinked submodules. Never `git stash` or `git add -A`.
- Local commits on branch `game-manager`. No push without the owner. Commit messages end with `Co-Authored-By: <the model that wrote the commit> <noreply@anthropic.com>`.

- Header, 20 bytes: magic `"\x00PSF"`, version u32, key-table offset u32, data-table offset u32, entry count u32.
- Each entry, 16 bytes: key offset u16, format u16 (0x0404 = int32; 0x0204 = UTF-8 string, NUL-terminated; 0x0004 = UTF-8 special, not terminated), length u32, max length u32, data offset u32.
- Keys are NUL-terminated strings in the key table.

// SPDX-License-Identifier: GPL-2.0-or-later

// Package sfo reads PS4 param.sfo files (the PSF key/value format in sce_sys/).
package sfo

import (
	"bytes"
	"encoding/binary"
	"errors"
	"fmt"
	"os"
	"sort"
)

const (
	fmtSpecial = 0x0004
	fmtString  = 0x0204
	fmtInt     = 0x0404
	headerSize = 20
	entrySize  = 16
)

type value struct {
	str   string
	num   uint32
	isInt bool
}

// File is a parsed param.sfo.
type File struct{ vals map[string]value }

// Entry is one key for Build.
type Entry struct {
	Key   string
	Str   string
	Int   uint32
	IsInt bool
}

// Load reads and parses a param.sfo file.
func Load(path string) (*File, error) {
	b, err := os.ReadFile(path)
	if err != nil {
		return nil, err
	}
	f, err := Parse(b)
	if err != nil {
		return nil, fmt.Errorf("%s: %w", path, err)
	}
	return f, nil
}

// Parse parses param.sfo bytes.
func Parse(b []byte) (*File, error) {
	if len(b) < headerSize || !bytes.Equal(b[:4], []byte("\x00PSF")) {
		return nil, errors.New("not a param.sfo (bad magic)")
	}
	le := binary.LittleEndian
	keyTab, dataTab, n := le.Uint32(b[8:]), le.Uint32(b[12:]), le.Uint32(b[16:])
	if uint64(headerSize)+uint64(n)*entrySize > uint64(len(b)) || keyTab > uint32(len(b)) || dataTab > uint32(len(b)) {
		return nil, errors.New("param.sfo truncated")
	}
	f := &File{vals: make(map[string]value, n)}
	for i := uint32(0); i < n; i++ {
		e := b[headerSize+i*entrySize:]
		keyOff := uint32(le.Uint16(e[0:])) + keyTab
		format, length, dataOff := le.Uint16(e[2:]), le.Uint32(e[4:]), le.Uint32(e[12:])+dataTab
		if keyOff >= uint32(len(b)) || uint64(dataOff)+uint64(length) > uint64(len(b)) {
			return nil, fmt.Errorf("param.sfo entry %d out of range", i)
		}
		end := bytes.IndexByte(b[keyOff:], 0)
		if end < 0 {
			return nil, fmt.Errorf("param.sfo entry %d: unterminated key", i)
		}
		key := string(b[keyOff : keyOff+uint32(end)])
		data := b[dataOff : dataOff+length]
		switch format {
		case fmtInt:
			if length < 4 {
				return nil, fmt.Errorf("param.sfo %s: short int", key)
			}
			f.vals[key] = value{num: le.Uint32(data), isInt: true}
		case fmtString, fmtSpecial:
			f.vals[key] = value{str: string(bytes.TrimRight(data, "\x00"))}
		default:
			return nil, fmt.Errorf("param.sfo %s: unknown format 0x%04x", key, format)
		}
	}
	return f, nil
}

// String returns a string value.
func (f *File) String(key string) (string, bool) {
	v, ok := f.vals[key]
	if !ok || v.isInt {
		return "", false
	}
	return v.str, true
}

// Int returns an int32 value.
func (f *File) Int(key string) (uint32, bool) {
	v, ok := f.vals[key]
	if !ok || !v.isInt {
		return 0, false
	}
	return v.num, true
}

// Keys returns the keys in sorted order.
func (f *File) Keys() []string {
	ks := make([]string, 0, len(f.vals))
	for k := range f.vals {
		ks = append(ks, k)
	}
	sort.Strings(ks)
	return ks
}

// Build writes a param.sfo with the given entries (sorted by key, as the PS4 tools do).
func Build(entries []Entry) []byte {
	es := append([]Entry(nil), entries...)
	sort.Slice(es, func(i, j int) bool { return es[i].Key < es[j].Key })
	var keys, data bytes.Buffer
	idx := make([]byte, 0, len(es)*entrySize)
	le := binary.LittleEndian
	for _, e := range es {
		var rec [entrySize]byte
		le.PutUint16(rec[0:], uint16(keys.Len()))
		keys.WriteString(e.Key)
		keys.WriteByte(0)
		le.PutUint32(rec[12:], uint32(data.Len()))
		if e.IsInt {
			le.PutUint16(rec[2:], fmtInt)
			le.PutUint32(rec[4:], 4)
			le.PutUint32(rec[8:], 4)
			var v [4]byte
			le.PutUint32(v[:], e.Int)
			data.Write(v[:])
		} else {
			n := uint32(len(e.Str) + 1)
			max := (n + 3) &^ 3
			le.PutUint16(rec[2:], fmtString)
			le.PutUint32(rec[4:], n)
			le.PutUint32(rec[8:], max)
			data.WriteString(e.Str)
			data.Write(make([]byte, max-n+1))
		}
		idx = append(idx, rec[:]...)
	}
	for keys.Len()%4 != 0 {
		keys.WriteByte(0)
	}
	out := make([]byte, headerSize, headerSize+len(idx)+keys.Len()+data.Len())
	copy(out, "\x00PSF")
	le.PutUint32(out[4:], 0x0101)
	le.PutUint32(out[8:], uint32(headerSize+len(idx)))
	le.PutUint32(out[12:], uint32(headerSize+len(idx)+keys.Len()))
	le.PutUint32(out[16:], uint32(len(es)))
	out = append(out, idx...)
	out = append(out, keys.Bytes()...)
	return append(out, data.Bytes()...)
}
```

// SPDX-License-Identifier: GPL-2.0-or-later

// Package events writes the engine's progress for the PS4 Native app: one JSON object per line
// with --json, plain text otherwise. See docs/game-manager-engine.md.
package events

import (
	"encoding/json"
	"fmt"
	"io"
	"sync"
)

// CodeError is the error returned by Writer.Error; Code is the machine-readable reason.
type CodeError struct{ Code, Msg string }

func (e *CodeError) Error() string { return e.Msg }

// Writer emits events for one operation (op). It is safe for concurrent use.
type Writer struct {
	mu   sync.Mutex
	w    io.Writer
	op   string
	json bool
}

// New returns a writer for operation op.
func New(w io.Writer, op string, jsonMode bool) *Writer { return &Writer{w: w, op: op, json: jsonMode} }

type event struct {
	Event   string `json:"event"`
	Op      string `json:"op"`
	Stage   string `json:"stage,omitempty"`
	Done    *int64 `json:"done,omitempty"`
	Total   *int64 `json:"total,omitempty"`
	Unit    string `json:"unit,omitempty"`
	Code    string `json:"code,omitempty"`
	Message string `json:"message,omitempty"`
	Result  any    `json:"result,omitempty"`
}

func (w *Writer) emit(e event, human string) {
	w.mu.Lock()
	defer w.mu.Unlock()
	if w.json {
		e.Op = w.op
		b, err := json.Marshal(e)
		if err != nil {
			b, _ = json.Marshal(event{Event: "error", Op: w.op, Code: "io", Message: err.Error()})
		}
		w.w.Write(append(b, '\n'))
		return
	}
	fmt.Fprintln(w.w, human)
}

// Progress reports done of total units in a stage.
func (w *Writer) Progress(stage string, done, total int64, unit, msg string) {
	w.emit(event{Event: "progress", Stage: stage, Done: &done, Total: &total, Unit: unit, Message: msg},
		fmt.Sprintf("[%s] %s %d/%d %s %s", w.op, stage, done, total, unit, msg))
}

// Warning reports a non-fatal problem.
func (w *Writer) Warning(msg string) {
	w.emit(event{Event: "warning", Message: msg}, fmt.Sprintf("[%s] warning: %s", w.op, msg))
}

// Error reports a fatal problem and returns it as a *CodeError for the caller to return.
func (w *Writer) Error(code, msg string) error {
	w.emit(event{Event: "error", Code: code, Message: msg}, fmt.Sprintf("[%s] error (%s): %s", w.op, code, msg))
	return &CodeError{Code: code, Msg: msg}
}

// Done reports success with an optional result object.
func (w *Writer) Done(result any) {
	w.emit(event{Event: "done", Result: result}, fmt.Sprintf("[%s] done", w.op))
}
```

Header layout (big-endian; check every offset against the port notes and cite them in comments):
- `0x000` magic `0x7F434E54`;
- `0x010` entry count u32;
- `0x018` entry table offset u32;
- `0x040` content id, 36 bytes;
- `0x070` DRM type u32;
- `0x074` content type u32;
- `0x410` PFS image offset u64;
- `0x418` PFS image size u64.

Each entry is 32 bytes: id u32, name offset u32, flags1 u32 (bit 31 = encrypted), flags2 u32, data offset u32, data size u32, padding 8. The well-known ids, `0x1000` param.sfo and `0x1200` icon0.png, and the full id → name table come from the port notes.

### Task 5: `pkg/fpkg` — PFS walk, PFSC, extraction with progress

**Files:**
- Create: `pkg/fpkg/pfs.go`

- Paths are validated: no `..`, no absolute paths, and no symlinks out of `dst`.

### Task 6: `pkg/library` — layout, library.json, import (PKG/folder, patch, DLC, resume)

**Files:**
- Create: `pkg/library/library.go`
- Test: `pkg/library/library_test.go`

**Interfaces:**
- Consumes: `fpkg.Open/Kind/Extract/SFO/ReadEntry/Signing` (Tasks 4–5), `sfo.Load` (Task 1), `events.Writer` (Task 2).
- Produces:
  - `type Library struct{ Root string }`;
  - `func (l Library) GameDir(titleID string) string`, `ContentDir`, `BuildDir`, `LogsDir`;
  - `type Game struct { TitleID, ContentID, Title, AppVer, Version string; Patches []string; DLC []string; ContentBytes int64; Status string; BuiltWith string; LastPlayed string; PlaySeconds int64 }`, the JSON fields in snake_case;
  - `func (l Library) Load() (map[string]*Game, error)`, `func (l Library) Save(games map[string]*Game) error` (atomic: temp file in the same dir, then `os.Rename`);
  - `type ImportResult struct { TitleID, Kind string; Game *Game; Pending bool }`;
  - `func (l Library) Import(src string, mode string, ev *events.Writer, cancel <-chan struct{}) (*ImportResult, error)`, where mode is `"copy"` or `"reference"` (folders only);
  - pending patches are stored under `Root/pending/<TITLE_ID>/` and applied when the base arrives.

Rules:
- **Game PKG:**
  - Extract into `games/<ID>/content.partial`, skipping files whose size and SHA-256 already match there, then rename to `content`.
  - If `content` already exists, it is a reinstall: extract into `content.partial`, then swap.
  - Then apply any pending patch.
- **Patch PKG:**
  - If the base exists, extract into `games/<ID>/patch.partial`, then move each file over `content` (replace), record it in `Patches` and update `AppVer` from the patch SFO.
  - If the base does not exist, extract into `pending/<ID>/` and return `Pending: true`.
- **DLC PKG:** extract into `content/addcont/<entitlement>`. The entitlement is the last field of the CONTENT_ID after `-` (`UP9000-CUSA00557_00-<label>` → `<label>`). Record it in `DLC`.
- **Folder:**
  - It needs `eboot.bin` and `sce_sys/param.sfo`. CATEGORY gd, or no CATEGORY, is treated as a game.
  - `copy` uses `clonefile` (`golang.org/x/sys/unix.Clonefile` if the module already vendors it; otherwise `cp -c -R`) and falls back to a byte copy.
  - `reference` writes `content` as a symlink to the folder.
- **Disk space:**
  - Check free space with `syscall.Statfs` against `UnpackedSize() + 1 GiB` before starting. If short, return `events` code `no_space`.
- **Errors:**
  - Any error removes the `.partial` dirs.
  - `fpkg.ErrRetail` maps to code `retail_pkg` and `fpkg.ErrCancelled` to `cancelled`.
- Progress events: stage `extract`, unit `bytes`.

func runJSON(t *testing.T, args ...string) (lines []map[string]any, err error) {
	var buf bytes.Buffer
	old := stdout
	stdout = &buf
	defer func() { stdout = old }()
	err = Execute(args)
	for _, l := range strings.Split(strings.TrimSpace(buf.String()), "\n") {

		}
		lines = append(lines, m)
	}
	return lines, err
}
